## 📌 Overview

This project applies Linear Algebra concepts to student-performance data. The assignment requires vectors, norms, dot/cross products, projection, matrix operations, dimensional geometry, and eigenvalues/eigenvectors of the covariance matrix. fileciteturn6file1L60-L87

## 🎯 Objectives

- Represent student scores as vectors and matrices.
- Calculate Norm-1 and Norm-2.
- Calculate dot product, angle, cross product and projection.
- Perform matrix addition, multiplication, transpose, inverse and determinant.
- Explain 2D, 3D and higher-dimensional geometry.
- Calculate covariance-matrix eigenvalues and eigenvectors. fileciteturn6file1L61-L80

## 🧮 Part A — Vectors

The notebook represents each student's subject scores as a vector and calculates:

- Norm-1
- Norm-2
- Dot product
- Angle between vectors
- Cross product
- Vector projection

These are the exact vector operations required by the assignment. fileciteturn6file1L61-L67

## 🔢 Part B — Matrices

The student × subject matrix is used for:

- Matrix addition
- Matrix multiplication
- Transpose
- Inverse, when possible
- Determinant

These operations are required in Part B of the assignment. fileciteturn6file1L69-L73

## 📐 Part C — Geometry

The project connects dataset dimensions with:

- Lines in 2D
- Planes in 3D
- Hyperplanes in higher dimensions
- The progression from 2D → 3D → higher-dimensional spaces

This follows the Part C requirements. fileciteturn6file1L75-L77

## 🧠 Part D — Eigenvalues & Eigenvectors

The covariance matrix of subject scores is calculated and decomposed using eigenvalues and eigenvectors.

The eigenvalues indicate the amount of variance captured along different directions, while eigenvectors represent those directions. The assignment specifically requires eigenvalues and eigenvectors of the covariance matrix. fileciteturn6file1L79-L80
